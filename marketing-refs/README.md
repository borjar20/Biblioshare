# Referencias para el motion graphic de Biblioshare

Material de referencia para generadores de vídeo y montaje. No lo usa la app.

- `ardilla-frontal-x8-*.png` — ardilla base adulta de PixelLab (`9de30514-…`, ver
  `scripts/pet-pixellab/characters.json`), rotación `south`, sprite de 64 px recortado y
  escalado ×8 con vecino más próximo (sin suavizado ni colores nuevos).
- `logo-icono-2048.png` — icono de app (tres lomos sobre `#b0542f`), proporciones del mockup
  de `src/lib/app-icon.tsx`, marca centrada en vertical.
- `logo-lomos-transparente.png` — solo los lomos, fondo transparente.
